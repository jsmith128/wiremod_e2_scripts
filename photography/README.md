The goal of this project is to scan an environment like a camera, record & process distance data, and draw to a digital screen. It can draw a greyscale depth map image of an environment, and even change the color of entities (though it is limited to drawing entity hitboxes, rather than the visible parts). It's a physical scanner.

Written over the course of a day or two, around October 27th 2025. It was originally created purely with wiremod "gates."
